# Saad Hashmani — website

Static one-page site: `index.html` plus the files it loads.

- Background: one combined video (`assets/video/loopscroll-*.mp4`). Pick quality with `?quality=480|720|1080` (default 720, 480 on phones).
- Contact form posts to `submit.php`. On the server, copy `config.example.php` to `config.php` and fill in the MySQL details (`config.php` is gitignored).
